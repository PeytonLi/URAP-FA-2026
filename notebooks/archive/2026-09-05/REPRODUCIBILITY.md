# Reproduce This Evidence Package

## What Can Be Reproduced

The package is standalone for **offline replay of the presented statistics,
tables, figures and report from saved responses**. No API key, GPU, model weight
or private face image is needed for that replay. Historical originals are copied
under `reference/` with SHA-256 provenance. The frozen training spreadsheet is
preserved byte-for-byte; it is not regenerated by an LLM during analysis.

New generation is reproducible as a documented procedure, not guaranteed
byte-identical sampled text. Hosted backend weights are not verifiable. Exact
historical DPO retraining is additionally limited by unrecorded source commits,
model-serving versions and a subsequently corrected dataset gate. Do not call
those limitations fully deterministic end-to-end reproduction.

## Clean Local Setup And Replay

```bash
cd /path/to/URAP/2026-09-05
python3.11 -m venv .venv
.venv/bin/python -m pip install -r locks/analysis-macos-py311.txt
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python scripts/verify_package.py
.venv/bin/python scripts/reproduce.py
```

The lock records the actual tested environment. On another OS, install
`.[dev,report]` from `pyproject.toml`, record your environment, and compare numeric
CSV outputs; PNG font rendering can differ across platforms. The report and
glossary record original local paths as well as portable relative paths. Some
machine-readable evidence records use your current clone root and therefore
differ after relocation. The formal report retains the original documented root
and is byte-identical on the tested environment.
`scripts/reproduce.py` never generates new model responses or starts a pod.
A fresh virtual environment installed the public bundle successfully and passed
the dependency consistency check. Its 56 tests passed and two private-image hash
tests were explicitly skipped. All 64 compared analysis CSVs, PNG/PDF figures,
formal report files and appendix CSVs matched the original hashes. With the
private bundle present, all 58 tests pass. The receipt is
`report/PUBLIC_REPLAY_CHECK.json`. The dependency lock excludes this unpublished
local project, which is installed separately with `pip install --no-deps -e .`.
Run `python scripts/check_public_replay.py` to repeat the full isolated-install
and replay check; installation needs package-index access, but analysis makes
no model calls.
The public clone uses the extracted requested-variable CSV when the private
request DOCX is absent. Private image-check receipts are retained as historical
checks, not claimed to have been rechecked on a clone without images. New
inference always requires freshly verifying the private image bytes.

## Main Files

- `scripts/analyze_evidence.py`: input normalization, clustering, p-values,
  confidence intervals and explicit BH families.
- `scripts/plot_evidence.py`: all 15 final presentation figures, with Gemma first.
- `scripts/build_evidence_records.py`: requested-variable records, DPO audit,
  complete column dictionary, coverage matrix and missing-information records.
- `scripts/build_formal_report.py`: authoritative formal PDF/Markdown report,
  all attached-column definitions and all RA requested-variable responses.
- `scripts/audit_sep5files.py`: compares the supplied exports with canonical
  raw records. It does not silently repair or overwrite the supplied files.
- `scripts/build_report.py`: legacy compact-summary/table helper; its compact
  PDF and Markdown are not included as competing presentation versions.
- `src/multimodel_bias/`: preserved protocol definitions, parsers, dataset tools,
  OpenRouter client, reusable scoring and historical analysis implementations.
- `tests/`: parsing, routing, task integrity, budgets and statistical unit tests.
- `config/`, `data/frozen/`, `data/iat12/manifest.csv`: exact models, prompts,
  sample selection, image hashes and generation parameters.
- `results/analysis/`: canonical cross-model raw/scored CSVs and statistics.
- `report/plot_registry.csv`: figure-to-input-to-code links and rebuild commands.

## New Model Generation

Read `config/study.json` before any paid calls. The September5 ceilings were
$5 OpenRouter with at least$10 reserve, and one H10080GB with up to3 GPU hours.
No Claude, Gemini-direct, or OpenAI-direct API was called in this session.

Secrets are read from environment or macOS Keychain, never source files. Existing
local Keychain service names are `openrouter-api-key` and `runpod-api-key`.
Do not put secrets in command-line arguments, JSON manifests or GitHub.
`scripts/preflight_access.py` checks account access and catalog/route metadata.
Its Keychain calls use the current macOS username. RunPod also requires the SSH
private key corresponding to the account's registered public key.

Hosted neutral12 VisBias was executed with:

```bash
.venv/bin/python scripts/run_hosted_visbias12.py --probe
.venv/bin/python scripts/run_hosted_visbias12.py
```

The probe's16 calls are part of the final288 rows, not an extra duplicate trial.
The runner resumes completed task IDs and validates pinned catalog/provider
routes with fallback disabled. Do not edit frozen inputs after generation.

The previously unavailable GPT UTKFace cell was run with the frozen August31
contract and images, including recorded model-specific unsupported parameters:

```bash
.venv/bin/python -m multimodel_bias.cli_iat \
  --run-id gpt_utkface_recovered_20260905 --models gpt56_luna \
  --stimulus-manifest data/frozen/utkface/utkface_iat_evaluation_manifest.csv \
  --output-root results/utkface_recovered --max-run-cost 1 \
  --minimum-balance 12.2 --max-workers 2 --minimum-request-interval 1 \
  --timeout 60 --max-retries 0
```

Preserved original responses are not overwritten on replay. To run another
generation study, use a new independently versioned output location/manifest,
record route snapshots and obtain a new session budget. Do not keep sampling
until a desired p-value or bias effect appears.

## Image Access

Private images are intentionally excluded from the proposed public GitHub set.
Their hashes and source references are included. For inference, obtain images
through the dataset's permitted access path or the researcher's private bundle,
then use `scripts/run_local_gemma.py --dry-run` to verify every local image hash.

- Neutral12: exact files in `data/iat12/images/`, hashes in manifest. The archive
  attributes them to Project Implicit; exact download URLs are not in this manifest.
  Use the researcher's authorized private bundle rather than guessing replacement images.
- UTKFace: selected cropped images under `data/private/utkface/raw/UTKFace/`.
  `utkface_freeze_manifest.json` records official source, transport mirror,
  immutable mirror revision and archive hash. Non-commercial research terms
  and original image-owner rights still apply.
- VisBias: exact normalized images under `data/private/visbias/normalized/`;
  source revision, original and normalized hashes in frozen manifests.
- FairFace DPO100: privately materialized PNGs in `data/private/fairface_dpo100/`;
  `report/dpo_image_audit.csv` maps the unchanged historical paths to current paths.

Dataset metadata are not a guarantee of demographic/age/expression truth or
person-disjointness. Do not infer missing protected labels from filenames beyond
the dataset's documented coding scheme.

## Local Pinned Gemma Inference

The deployed RunPod uses the existing80GB network volume, not a new dataset or
model download. Only compute/container is terminated after output verification;
the network volume remains intact. The tested Linux/PyTorch environment is
recorded in `results/gemma_local/manifest.json` and `locks/gemma-linux-environment.json`.

```bash
/workspace/gemma3-fairface-debiasing-august10/.venv/bin/python \
  /workspace/research-evidence-september5/scripts/run_local_gemma.py \
  --model-dir /workspace/.hf/hub/models--google--gemma-3-12b-it/snapshots/96b6f1eccf38110c56df3a15bffe176da04bfd80
```

The job was actually launched with `scripts/remote_job.py launch --probe`, then
`scripts/remote_job.py launch`. `scripts/watch_runpod.py` checks progress, downloads
outputs with `rsync`, verifies every remote hash and releases compute. Fresh
deployment uses `scripts/runpod_control.py deploy`; it refuses duplicate state
and uses GraphQL because the REST region enum omitted the existing US-NE-1
volume region. Do not replay deployment against an existing run-state file.

The frozen queue contains956 tasks. The eight-task compatibility probe is kept
separate and not counted as additional scientific samples. The full task manifest,
raw output, base hashes, precision, effective generation config, GPU and versions
are preserved. A new run refuses to overwrite an existing response file.

The run completed without runtime errors, but 36/48 DecodingTrust outputs hit
the 150-token cap. Those counts are diagnostic only. A future valid full-response
estimate needs a newly versioned, longer-budget run of the entire fixed panel,
not just selected problematic prompts. The neutral12 continuity check also failed
exact replay; main historical comparisons retain the original frozen baseline.

## BOLD Scoring

Offline figure replay uses saved scores. To recompute neural scorer outputs,
create a separate environment from `locks/bold-scorer-environment.json` and install
the exact package versions; obtain the pinned regard model and Detoxify checkpoint.
The source ID/revision/full checkpoint hash are validated by the scoring code.
Set caches inside this package, not the original August17 project:

```bash
HF_HOME="$PWD/.model-cache/huggingface" \
TORCH_HOME="$PWD/.model-cache/torch" \
HF_HUB_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
python scripts/score_gemma_bold.py
```

The recorded execution reused the existing local BOLD-scoring interpreter, with
its cache copied into this new package. It re-scores16 archived texts and refuses
to accept drift in their toxicity/sentiment/regard classes before comparing the
100 new Gemma continuations. See `results/gemma_bold/scorer_manifest.json`.

## Historical DPO Reproduction Boundary

`reference/dpo/august10_code/` preserves the available source and original schema.
The selected100-row spreadsheet, freeze/training manifests, loss logs,
development scores and post-DPO neutral12 raw responses are bundled. The source
contains the updated gate that rejects the v4 train split's missing negative-IAT
coverage. **Do not disable that gate just to rerun a failed historical experiment.**

Historical model loading, fresh rank8 LoRA, beta0.05, LR2e-5, accumulation8,
80 microsteps/10 updates, mean-token reduction, seed8102026, BF16, SDPA and
response cap384 are recorded in the training manifest. The original exact shell
invocation and exact executed code commit are not recorded, so no fabricated
“exact command” or commit is supplied. Full deterministic historical candidate
generation is also unavailable: Codex/Claude backend snapshots were not pinned.

To reproduce the **reported DPO evaluation findings**, use the preserved response
CSVs and `scripts/plot_evidence.py`; no training is needed. To develop a new
adapter, first repair/refreeze the dataset with its own version and approval.
The frozen base and reference never become trainable parameters.
